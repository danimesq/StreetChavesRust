# Pascal effect catalog

This file is the ordered configuration source used by the Rust effect interpreter. It is copied from
https://github.com/danimesq/OpenStreetChaves/blob/main/Dados/Efeitos.ini
and preserves section and entry ordering, including duplicate numbered keys.
The Rust interpreter treats it as data, not executable Pascal code. Review the upstream
repository license and notices before redistributing original game assets alongside it.
